Task `.trellis/tasks/10-01-pump-io-shape`. Host: AMD Ryzen 9 9955HX, NixOS 26.11, .NET 10.0.12,
Release. Base revision `56dd85f`; measured-surface content fingerprint
`da99a967abddb3ccf9666812fb4dc168886e235a12879bd8d83a13d7a2591075` (see the artifact README for what it
covers — `git write-tree` returns the index tree, which predates this uncommitted change).
Instrument: `INdisReadPacketCalls` (`src/WinForward.NdisApi/NdisReadPacketCalls.cs`) — the
driver↔native seam — driven through `NdisApiDriver.CreateForTests` by
`tests/WinForward.Core.Tests/NdisApiReadShapeTests.cs`, which records every call's name, order and
requested count. **What this proves and does not prove** is `design.md` §3.2: the recorded call

semantics the real driver implements (open items 1–3 of the artifact README).

Commands (all from the repository root):

```bash

# red capture 1 (instrumented pre-change body, guard absent):
```

## 1. After — per-drain call shape (exact, `NdisApiReadShapeTests`)

Recorded sequences; `Read(n)` / `Query` name the seam calls and `n` is the requested slot count.

| Drain | Recorded order | Requested counts | Drives |
|---|---|---|---|
| non-empty, read succeeds with 4 | `[Read]` | `[32]` | `SpeculativeReadIssuesOneReadAndNoQueryForANonEmptyDrain` |
| empty, read succeeds with 0 (hypothesis B) | `[Read]` | `[32]` | `AnEmptyQueueYieldsZeroPacketsWithNoErrorUnderEitherReadResult` |
| empty, read fails, query 0 (hypothesis A) | `[Read, Query]` | `[32]` | same fact |
| empty, read fails, query fails | `[Read, Query]` | `[32]` | `AFailedReadWithAFailedQueryStillThrowsTheQueryError` (throws the query error) |
| non-empty, read fails, guard's first observation | `[Read, Query, Read]` | `[32, 3]` | `AMismatchHealsTheShapeInsteadOfThrowing` |
| same handle, later non-empty drains (sticky) | `[Query, Read]` | `[3]` | `TheGuardFiresExactlyOnceAndLaterDrainsAreQueryFirst` |
| non-empty, read fails, probe fails too | `[Read, Query, Read]` | `[32, 3]` | `AGuardedProbeThatAlsoFailsThrowsTheReadErrorLikeToday` (throws the read error) |
| 1,000 mixed conforming drains | 1,000 × `[Read]`, zero `Query` | all `[32]` | `TheGuardNeverFiresOnAConformingDriver` |

Counter read-outs at the seam (`NdisApiDriver.ReadDiagnostics`, asserted by
`TheReadDiagnosticsCountOneReadPerDrainAndOneQueryOnlyOnAFailedRead`): three drains
(non-empty / empty / failed-read-then-query-0) ⇒ `BatchReads 3, QueueSizeQueries 1, EmptyReads 2,
FailedReads 1, LastFailedReadNativeError 31, ReadShapeMismatchCount 0`. The conforming 1,000-drain
series ⇒ `QueueSizeQueries 0, FailedReads 0, ReadShapeMismatchCount 0`. The healed series ⇒
`BatchReads 5, QueueSizeQueries 4, ReadShapeMismatchCount 1` (four drains, five reads: the healing
drain's probe is the extra one).

Driver-internal derived counts, before → after, per drain:

| Drain | Before (derived, notes §7) | After (recorded above) |
|---|---|---|
| non-empty, read OK | query + read = 2 IOCTLs | 1 read, 0 queries |
| empty | 1 query, 0 reads | 1 read, 0 queries (hypothesis B) / 1 read + 1 query (hypothesis A) |
| non-empty, first read failure for the handle | query + read + throw | read + query + probe read; heals once per handle |
| same handle afterwards | query + read + throw | query + read + throw, byte-identical to before |

The null-slot contract moved with the shape: a null hole in the caller array now throws
`ArgumentNullException` from `BuildMultiRequest` on **every** drain, because the request always
walks the whole array (`ANullHoleInTheBatchArrayThrowsOnADrainThatWouldOtherwiseBeEmpty`).

Body: `TryReadPackets` calls `ReadQueryFirst` unconditionally (the query leads; the read is issued
only when the query reports non-empty). No guard, no read-first attempt. Result:

## 3. Red capture 2 — the read-first body without the guard

Body: the landed read-first shape with the §3.5 guard point removed (`read failed + query > 0` throws
immediately), driven through a **real** `NdisCapturePump` over a **real** `NdisApiDriver` built by
`CreateForTests` with a fake whose every read fails (error 31) and whose query reports 3 queued.
`TransientRetryBaseDelay = TimeSpan.Zero` so the retry budget is crossed without waits.

| Fact | Failure |
|---|---|
| `TheMismatchNeverReachesTheTransientRetryBudget` | `Expected: "False\|0\|0\|0" / Actual: "True\|5\|1\|31"` — `IsDegraded = true`, `TransientReadRetryCount = 5`, `TransientReadIncidentCount = 1`, `LastDegradedNativeErrorCode = 31`. The pump never delivered the packet: the run completed **without** throwing (a degraded exit), so the fact's normal `Assert.ThrowsAnyAsync<OperationCanceledException>` saw no exception at all. |
| `AGuardedProbeThatAlsoFailsThrowsTheReadErrorLikeToday` | `Expected: 1 / Actual: 0` (mismatch count; the sticky flag is likewise false) |

This is the false degradation the guard removes: a working adapter with packets available loses
interception after five retries, and no diagnostic is published. Both red bodies were temporary —
the landed tree is the read-first shape **with** the guard, and the fact is green there.

## 5. Byte gates at the seam

`NdisApiReadShapeTests.DriverReadPathAllocatesNoManagedBytes`: 1,000 drains per probe batch over a
non-recording fake cycling `{4, 0}` (packet and empty drains both in the window), the standard window
contract (exactly-zero probe batches, unchanged managed thread id, `Assert.Equal(0, allocated)`, a
thread-independent call-count backstop of 1,000). Green. `pump.idleEvent`'s own 0 B throw covers the
~150 real 100 ms timeouts; the discrimination re-proof for this gate is in `gate-stability.txt`.
